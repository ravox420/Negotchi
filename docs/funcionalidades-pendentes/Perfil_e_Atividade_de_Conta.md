# Perfil e Atividade de Conta

## Objetivo

Exibir informações de perfil, uso e atividade de conta de forma consultável.

## Contexto

O Negotchi mostra e-mail quando informado e limites resumidos, além de `/usage`. O Codex Desktop possui uma área de perfil e atividade mais abrangente.

## Restrição

Dados indisponíveis devem ser identificados como tal. Informações de conta são de leitura e não devem expor credenciais ou dados de outras contas.

## Finalizado Quando

O usuário consegue abrir uma área de perfil que mostra a conta conectada, limites e atividade disponível, com estados claros para carregamento, ausência de dados e falha.
