# Gerenciamento de Plugins

## Objetivo

Permitir descobrir, instalar, configurar e remover plugins disponíveis para o Codex.

## Contexto

O Negotchi permite selecionar skills existentes e consultar MCPs, mas não fornece catálogo ou ciclo de vida de plugins como o Codex Desktop.

## Restrição

Instalação e conexão de plugin devem expor permissões, origem e dependências antes da confirmação. Não deve instalar componentes silenciosamente.

## Finalizado Quando

O usuário consegue ver plugins disponíveis e instalados, revisar suas permissões e realizar instalação, configuração, atualização ou remoção mediante confirmação.
