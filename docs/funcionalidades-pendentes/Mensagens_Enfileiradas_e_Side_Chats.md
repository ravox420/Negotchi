# Mensagens Enfileiradas e Side Chats

## Objetivo

Permitir orientar um trabalho em curso e fazer perguntas laterais sem interromper ou perder a tarefa principal.

## Contexto

Hoje o usuário precisa aguardar ou interromper a resposta para enviar uma nova mensagem. O Codex Desktop aceita mensagens de direcionamento e conversas laterais.

## Restrição

Não substitui a execução paralela de tarefas independentes. Uma mensagem lateral não pode herdar permissão para alterar a tarefa principal.

## Finalizado Quando

Durante uma tarefa ativa, o usuário consegue enfileirar uma orientação para o próximo ponto seguro e abrir uma pergunta lateral cujo resultado não altera o contexto principal.
