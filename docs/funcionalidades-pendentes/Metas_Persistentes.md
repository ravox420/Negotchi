# Metas Persistentes

## Objetivo

Permitir definir um resultado verificável para que o agente prossiga por várias etapas até concluí-lo, pausar ou identificar bloqueio.

## Contexto

O Negotchi encerra cada pedido ao concluir um turno. O Codex Desktop oferece Goals para trabalhos longos com condição de término.

## Restrição

Uma meta precisa ter objetivo, limites e forma de verificação explícitos. Ela não pode ignorar sandbox, aprovações ou decisões do usuário.

## Finalizado Quando

O usuário consegue criar, acompanhar, pausar e encerrar uma meta, e a interface mostra o estado e a evidência usada para marcá-la como concluída ou bloqueada.
