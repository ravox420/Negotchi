# Computer Use no Windows

## Objetivo

Permitir que o agente opere aplicativos Windows em uma tarefa delimitada, mediante aprovação.

## Contexto

O Negotchi abre caminhos locais por ferramenta própria, mas não possui uma superfície para o agente ver, clicar e digitar em aplicativos. O Codex Desktop suporta Computer Use no Windows.

## Restrição

A tarefa deve informar o aplicativo e a finalidade. A execução deve respeitar permissões, usar o desktop ativo conforme aplicável e permitir interrupção imediata pelo usuário.

## Finalizado Quando

O usuário consegue iniciar uma tarefa aprovada de Computer Use, acompanhar suas ações e interrompê-la; a interface registra o resultado e quaisquer solicitações de permissão.
