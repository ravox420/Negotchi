# Navegador Integrado

## Objetivo

Permitir abrir e verificar páginas locais ou públicas dentro do aplicativo.

## Contexto

O Negotchi abre caminhos no aplicativo padrão do Windows, mas não inclui navegador para validação de interfaces. O Codex Desktop disponibiliza Browser para esse uso.

## Restrição

O acesso a sites deve respeitar a política de rede e permissões configuradas. Não inclui automação de aplicativos Windows, que é um escopo separado.

## Finalizado Quando

O usuário consegue abrir uma URL permitida, navegar na página e fornecer um comentário de contexto para que o agente use na tarefa atual.
