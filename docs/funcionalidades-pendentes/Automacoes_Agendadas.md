# Automações Agendadas

## Objetivo

Permitir executar rotinas recorrentes associadas a uma conversa ou projeto.

## Contexto

O Negotchi não agenda trabalho. O Codex Desktop pode executar automações em segundo plano e registrar suas execuções.

## Restrição

Uma automação deve informar agenda, contexto, modelo e permissões antes de ser ativada. Nenhuma execução pode ampliar o acesso aprovado para a conversa.

## Finalizado Quando

O usuário consegue criar, pausar, retomar e remover uma automação, além de consultar o histórico, resultado e falhas de cada execução.
