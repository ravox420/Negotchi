# Painel de Git

## Objetivo

Dar visibilidade e controle básico do repositório associado à conversa.

## Contexto

O Negotchi pode permitir alterações por meio do agente, mas não expõe status, branch ou operações Git. O Codex Desktop incorpora esse fluxo.

## Restrição

Operações que alteram o repositório exigem confirmação adequada. Não inclui revisão visual de diff nem integração de pull request, que possuem escopo próprio.

## Finalizado Quando

O usuário consegue ver status e branch, inspecionar arquivos modificados e executar stage, unstage, revert, commit e push com confirmação antes de ações destrutivas ou remotas.
